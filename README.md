# Nairpsicologa

Recrie EXATAMENTE o layout das imagens anexadas (versão desktop e versão mobile) como uma landing page real, responsiva e funcional, para a psicóloga Nair Guimarães. Siga fielmente a estrutura, a disposição dos elementos, as cores, as fontes, os espaçamentos, os cantos arredondados e o estilo dos ícones das imagens. Use as fotos anexadas da psicóloga nos mesmos lugares em que ela aparece no layout.
